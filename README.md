## 🌐 Features

- **Responsive Design:** A clean, emotive UI that reflects the studio's pastel aesthetic, built with custom Web Components (`<cs-navbar>`, `<cs-footer>`), smooth dark/light mode, and reduced-motion accessibility.
- **Projects & Creations Page (`pages/projects.html`):** An interactive project catalog with category filtering, real-time search, and live in-browser rendering of each project's dedicated Markdown (`.md`) file using Marked.js.
- **Featured Projects Showcase:** Flagship tools and stories highlighted directly on the homepage with deep-links to documentation.
- **Signature Wall:** A collective community database powered by client-side SQLite (`sql-wasm.js`) and GitHub Actions.
- **Mission & Philosophy Pages:** Deep insights into our Fractal Studio model, targeted licensing strategies, and Ethical Human-AI Alliance.

---

## **🛠 Tech Stack**

* **Frontend:** Modern semantic HTML5, Tailwind CSS, Vanilla Web Components, Lucide Icons.
* **Markdown Engine:** Client-side Marked.js (`assets/js/marked.min.js`).
* **Database:** SQLite in WebAssembly (`assets/js/sql-wasm.js`).
* **Local Server:** Built-in zero-dependency Node.js server (`server.js`).
* **Hosting:** GitHub Pages with automated deployment workflow.
* **License:** Distributed under the **GNU AGPL v3**.

---

## 💻 Running Locally

Start the website locally using Node.js:

```bash
# Using Node directly
node server.js

# Or using npm
npm start
```

Open your browser at **http://localhost:3000**!
