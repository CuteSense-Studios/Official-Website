# 🎮 As You Are (Ren'Py Template & Engine)

> **"The open-source Ren'Py game engine template and dialogue framework powering the visual novel 'As You Are'."**

---

## 🌟 What is As-You-Are-T?

**As-You-Are-T** is an open-source starter framework and boilerplate designed for creators, narrative designers, and indie game developers building emotional visual novels in **Ren'Py**. 

Originally built as the technical foundation for CuteSense Studios' visual novel *"As You Are"*, this repository provides clean, modular Ren'Py script architecture, pre-configured UI screens, customized save/load interfaces, and accessible audio mixing pipelines.

---

## 🎨 Framework Features

- **📖 Modular Script Organization:** Separates story arcs, character definitions, dialogue scripts, and music transitions into clean `.rpy` files.
- **🎨 Custom Pastel UI Theme:** Hand-styled dialogue textboxes, choice menus, quick-menu buttons, and preference sliders matching CuteSense's soft aesthetic.
- **🎧 Dynamic BGM Crossfading:** Helper functions for seamless transitions between rainy ambiance, character themes, and silent reflective beats.
- **♿ Accessibility Built-in:** High-contrast text toggle, adjustable font sizes, and self-voicing screen reader compatibility out of the box.
- **📦 Multi-Platform Packaging:** Ready-to-build configuration for Windows, macOS, Linux, and Web (HTML5/WebAssembly).

## 🚀 How to Use

1. **Install Ren'Py SDK:** Download the latest Ren'Py SDK from [renpy.org](https://www.renpy.org/).
2. **Clone the Template:**
   ```bash
   git clone https://github.com/CuteSense-Studios/As-You-Are-T.git
   ```
3. **Launch in Ren'Py:** Add the project folder to your Ren'Py launcher directory and click **Launch Project**.
4. **Customize Dialogue:** Edit `game/script.rpy` and add your custom character sprites and background art.
