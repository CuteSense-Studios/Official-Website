# 🌸 CuteSense Studios Official Website

> **"The official web home and emotive digital sanctuary of CuteSense Studios — featuring live Markdown project rendering, SQLite WebAssembly signature wall, and custom Web Components."**

---

## 🌟 Overview

The **Official Website** is the central digital hub of CuteSense Studios. Built with an ethos of **"Quality Art, Openly Created"**, the website balances whimsical, emotive visual design with high-performance, lightweight engineering.

It serves as the front door for our community, our philosophy, our business model, and our open-source software catalog.

---

## ✨ Standout Features

- **📂 Live Markdown Project Showcase:** Parses and renders `.md` project documentation directly from repository source files in the browser using Marked.js.
- **🖊️ SQLite WebAssembly Signature Wall:** A live community guestbook powered by in-browser SQLite (`sql-wasm.js`) and persistent GitHub Action automation.
- **🌙 Cohesive Theme & Micro-Interactions:** Seamless dark/light theme switching, kinetic button physics, and GPU-accelerated floating ambient animations.
- **🧩 Custom Web Components:** Modular, dependency-free `<cs-navbar>` and `<cs-footer>` custom elements.
- **♿ Accessible & Performant:** Zero third-party trackers, full keyboard navigation support, and strict `prefers-reduced-motion` compliance.

## 🛠️ Technology Stack

| Layer | Technology |
| :--- | :--- |
| **Markup & Layout** | HTML5 Semantic Elements & CSS Flexbox/Grid |

## 🚀 Local Development

Start the local server with one command:

```bash
# Using Node.js directly
node server.js

# Or using npm
npm start
```

Visit `http://localhost:3000/` in your browser!
