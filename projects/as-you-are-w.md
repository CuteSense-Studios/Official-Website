> **"The official web portal and emotional landing experience for 'As You Are' — an intimate indie visual novel exploring identity and human connection."**

---

## 📖 Overview

**As-You-Are-W** is the dedicated web showcase for CuteSense Studios' flagship visual novel, **"As You Are"**. Designed as a tranquil digital sanctuary, the site introduces visitors to the visual novel's world, character lore, original soundtrack previews, and development journey.

Reflecting the emotional resonance of the game itself, the web experience features soft animated mist effects, responsive typography, and an interactive audio player allowing visitors to preview the ambient OST before diving into the story.

---

## ✨ Web Highlights

- **🌸 Atmospheric Landing:** Delicate CSS animations and soothing color palettes mirroring coastal rain and ocean horizons.
- **🎵 Interactive OST Player:** Built-in ambient music sampler featuring original piano and acoustic compositions.
- **📜 Character Profiles & Art Gallery:** Interactive character cards introducing Ren and Maya with high-resolution concept illustrations and dialogue snippets.
- **📱 Fully Responsive:** Handcrafted to feel immersive across desktop, tablet, and mobile viewport sizes.
- **⚡ Zero Telemetry & Lightweight:** Fast loading with no third-party trackers or bloat.

## 🚀 Running Locally

```bash
# Clone the website repository
git clone https://github.com/CuteSense-Studios/As-You-Are-W.git
cd As-You-Are-W

# Open directly or run with node server
node ../server.js
# Or open index.html in your browser
```
