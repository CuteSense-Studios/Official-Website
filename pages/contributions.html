Building Together

Thank you for your interest in contributing! We welcome code, art, music, and voices from all backgrounds.

AI is a collaborator, not a replacement.

Quick Start

  • Comply with the project's specific license (MIT, CC BY-SA, etc.).
  • Disclosure is mandatory if AI tools are used.
  • You are responsible for the legality of your training data/tools.
  • Human review is mandatory for every single submission.

Workflow

  1. Find an issue or propose a new idea.
  2. Discuss significant changes before starting.
  3. Fork & branch with a descriptive name.
  4. Follow the AI disclosure rules.
  5. Test locally and open a Pull Request (PR).

Contribution Types

Specific rules for different creative fields

Code

Follow .editorconfig and linting rules. Add tests for new features. For AI use (>10 lines), include an inline comment with the tool and prompt used.

Art

Use open formats (PNG, SVG, WebP). AI assets must include a side-car _ai.txt file. No raw outputs—meaningful human editing is required.

Music & SFX

OGG, WAV, or FLAC preferred. Disclose AI tools and prompts in a .txt file. You must verify the AI tool's license allows open-source distribution.

Writing

Substantial AI text must be disclosed. Every contribution must receive a final human polish for tone, accuracy, and "cuteness".

AI Usage & Transparency

Permitted

  • • Ideation, drafts, and boilerplate
  • • Code refactoring & optimization
  • • Foundational assets (as a start)
  • • Accessibility improvements

Prohibited

  • • Raw, unmodified AI outputs
  • • Unethical/Copyright-violating models
  • • Restrictive/Non-OSS licenses
  • • Non-disclosure of AI usage

How to Disclose:

Include In-File Attribution (comments or metadata) and a summary in your PR Description detailing which tools were used and which components they influenced.

Questions?

For technical questions, open a GitHub Discussion. For policy or legal concerns, reach out to us directly.
